# Price Monitor — сервис отслеживания цен на Go и PostgreSQL

Практический пример backend-сервиса на **Go**, который отслеживает цены на товары, сохраняет историю изменений и предоставляет HTTP API для работы с данными.

Проект будет полезен разработчикам, которые хотят увидеть, как в реальном сервисе совместить **Go, PostgreSQL, фоновые воркеры, транзакции, Clean Architecture и Graceful Shutdown**.

## 💡 Какую задачу решает проект

Представим сервис, который должен следить за стоимостью товаров.

Для каждого товара система хранит текущую цену:

```text
iPhone 15 → 799.00
```

При очередном обновлении цена изменилась:

```text
799.00 → 749.00
```

Сервис одновременно:

1. обновляет текущую цену товара;
2. записывает изменение в историю;
3. выполняет эти операции внутри PostgreSQL-транзакции.

В результате можно получить как **актуальную цену**, так и полную историю её изменений.

Это позволяет использовать проект как основу для:

* мониторинга цен;
* отслеживания изменений товаров;
* сервисов аналитики;
* систем контроля данных;
* периодической обработки информации;
* будущих систем уведомлений.

## 🔄 Как работает фоновый воркер

После запуска приложения фоновый воркер периодически выполняет необходимые операции.

Упрощённая схема:

```text
        Запуск приложения
                │
                ▼
          time.Ticker
                │
                ▼
       Запуск обновления
                │
                ▼
       Получение товара
                │
                ▼
       Изменение цены
                │
                ▼
      PostgreSQL transaction
          ┌─────┴─────┐
          ▼           ▼
   Текущая цена   История цены
          └─────┬─────┘
                ▼
             COMMIT
```

Такой подход можно применять не только для цен, но и для любых задач, которые необходимо выполнять периодически.

## 🔐 Почему используются транзакции

Изменение текущей цены и добавление записи в историю являются связанными операциями.

Если обновить цену, но не записать историю, данные окажутся в несогласованном состоянии.

Поэтому операции выполняются атомарно:

```text
BEGIN
   │
   ├── UPDATE product
   │
   ├── INSERT price_history
   │
   ▼
 COMMIT
```

При ошибке выполняется `ROLLBACK`.

Это показывает практический способ защиты связанных изменений в PostgreSQL.

---

## 🛑 Graceful Shutdown

При получении сигнала завершения приложение не просто прекращает работу.

Оно корректно останавливает сервер и фоновые процессы, позволяя текущим операциям завершиться.

Например:

```text
Ctrl+C
  │
  ▼
Получение сигнала
  │
  ▼
Остановка новых операций
  │
  ▼
Завершение текущих задач
  │
  ▼
Закрытие ресурсов
  │
  ▼
Завершение приложения
```

Этот подход особенно полезен для сервисов с долгоживущими воркерами и фоновой обработкой.

---

## 💰 Почему используется `decimal`

Для денежных значений нежелательно использовать `float`, поскольку операции с числами с плавающей точкой могут приводить к ошибкам представления и округления.

Поэтому для цен используется:

```go
decimal.Decimal
```

Это полезный практический пример правильной работы с финансовыми значениями в backend-приложениях.

## ⚙️ Установка и запуск

### 1. Запустить PostgreSQL

Например, через Docker:

```bash
docker run --name price-db \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_USER=user \
  -e POSTGRES_DB=price_tracker \
  -p 5432:5432 \
  -d postgres:15-alpine
```

### 2. Установить инструмент миграций

```bash
go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest
```

### 3. Выполнить миграции

```bash
migrate -path migrations/ \
  -database "postgres://user:password@localhost:5432/price_tracker?sslmode=disable" \
  up
```

### 4. Запустить приложение

```bash
go run cmd/server/main.go
```
